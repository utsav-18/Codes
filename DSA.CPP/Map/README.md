# Map example (C++)

Compile (with g++ / MinGW / MSYS2):

```bash
g++ -std=c++17 MapCode.cpp -o map_example
```

Run (PowerShell / Command Prompt):

```powershell
./map_example.exe
# or
./map_example
```

The example demonstrates `std::map` operations: insert, operator[], emplace, iteration, find, erase, and ordering by key.
